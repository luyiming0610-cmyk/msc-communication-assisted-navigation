# N3 formal batch evidence

This directory contains the processed summary for the five paired three-robot shared-exit trials. `paired_trial_results.csv` contains one row per OFF/ON pair, `descriptive_statistics.csv` contains descriptive statistics, and the Excel workbook provides formula-backed calculations and a visual comparison. `communication_event_audit.txt` records the five discovery-to-route-switch chains. `raw_evidence_sha256_verification.csv` verifies the Windows evidence copy against the original WSL files.

Raw bags and diagnostic logs are intentionally excluded from Git and stored under `bags/shared_exit_n3_formal_20260722`. Excluded failures are documented in the parent directory's `N3_ATTEMPT_HISTORY.md` and are not included in these statistics.
