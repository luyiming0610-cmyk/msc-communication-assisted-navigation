# Objective 5 Condition C Trial 01：S形轨迹与控制平滑性审计

## 结论

本次正式实验数据有效，任务成功，无碰撞，最终自动停止。用户观察到的“约4–5次小幅S形避让”得到bag与控制器日志的明确支持。

但它**不是4–5次独立CPA重新触发**：两台车都只进入过一次`AVOID_TURN`、一次`AVOID_PASS`和一次`RECOVER`。S形来自同一个持续约20.7秒的`AVOID_PASS`阶段内，角速度指令方向反复改变。

两台车各发生 **9次转向方向反转**，形成10段正负交替的角速度区间，约对应肉眼看到的5个摆动波段。两车反转时序高度一致。

## 通信与任务判定

- 配置固定延迟：1.0s。
- 实测消息年龄均值：1.00018s / 1.00022s。
- 中位数：两方向均为1.0s。
- p99：1.00000s / 1.00980s。
- capture ratio：1.0 / 1.0。
- 丢包、重复、乱序：均为0。
- `DATA_VALIDITY=VALID`。
- `TASK_OUTCOME=SUCCESS`。
- 首次触发原因：`PREDICTED_CPA`。
- `LOCAL_*`进入次数：两车均为0，因此不是红外线/ToF接管。

## 安全性

- 最小中心距：0.14132m。
- 安全门槛：0.14000m。
- 安全余量：约1.32mm。
- 碰撞：否。

任务虽然成功，但安全余量很小，同时出现明显控制平滑性退化，不能仅用“最终成功”掩盖该行为变化。

## 科学解释与限制

现有证据强烈支持：1.0s固定延迟与`AVOID_PASS`阶段的周期性转向修正相关。控制器不断根据延迟的邻车状态调整角速度，产生了规律的S形轨迹。

但目前只有Condition C的一次正式trial，因此严谨表述应是：

> Condition C Trial 01成功完成避让，但出现与高固定延迟相关的显著转向振荡候选现象；是否为Condition C的可重复效应，需由Trial 02–05使用相同指标确认。

后续C02–C05必须继续统计角速度方向反转、航向累计变化、路径效率、LOCAL接管和安全余量，不得修改冻结控制器、阈值或几何。
